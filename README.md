# Vynora — AI-Powered E-Commerce Platform

Vynora is a full-stack AI-powered e-commerce platform built with React, Django REST Framework and modern AI technologies.

## Tech Stack

- React.js + Vite
- Bootstrap 5
- Django
- Django REST Framework
- JWT Authentication
- SQLite / MySQL
- AI API Integration
- Razorpay / Stripe
- Git & GitHub
